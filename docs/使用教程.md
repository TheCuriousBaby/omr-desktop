# OMR 阅卷助手使用教程

## 一、安装与启动

1. 把发行包里的 `OMR阅卷助手` 文件夹整个解压到本机，双击其中的 `OMR阅卷助手.exe`。
2. exe 必须和同级的 `_internal` 文件夹放在一起，不能单独拷出。需要桌面入口时，在 exe 上右键“发送到 → 桌面快捷方式”。
3. 如果被安全软件拦截或提示找不到 `python314.dll`，请把整个文件夹加入安全软件的信任列表，并确认 `_internal` 里的文件没有被隔离。

首次启动会自动创建“示例方案”和一张示例答题卡，数据保存在“文档\OMR阅卷助手”下：

| 目录 | 内容 |
| --- | --- |
| 方案 | 每个方案一个子文件夹，含模板、答案、空白答题卡 |
| 输出 | 每次阅卷的结果，按“方案名\时间”分目录 |
| 示例答题卡 | 示例图片 |

这些目录可以在“设置 → 常规”里修改。

## 二、五分钟上手：用示例方案跑一遍

1. 顶部“当前方案”选择“示例方案”。
2. 左侧点击“开始阅卷”，点“添加文件夹…”，选择“文档\OMR阅卷助手\示例答题卡”。
3. 点右上角“开始阅卷”，几秒后结果表会列出这张卡的准考号、各题答案和得分。
4. 点击结果表中的一行，右侧显示标注图：被识别为已涂的气泡会标出对应选项。
5. 点“导出结果…”可存为 Excel 或 CSV。

## 三、为自己的答题卡建立方案

一张新版式的答题卡需要建一次方案，之后同版式的卡可以反复使用。

### 1. 新建方案

点顶部“新建”，输入方案名称。方案名称不能含 `\ / : * ? " < > |`。

### 2. 载入空白答题卡

进入“版面模板”页，点“载入空白答题卡…”，选择一张没有填涂的答题卡图片（jpg、png 或 pdf）。几秒后画布上会显示预处理后的答题卡。

- 尽量用清晰、方正、光线均匀的图片；最好是和日后阅卷同样方式获得的图（扫描就用扫描件，拍照就用照片）。
- 画布操作：Ctrl+滚轮缩放，按住左键空白处拖动平移，“适应窗口”回到整页。

### 3. 设置页面与预处理

右侧切到“页面与预处理”页签。

页面尺寸：模板坐标所基于的图像大小。保持默认即可；想让坐标更精细，可把宽高同比例调大。修改后画布底图会按新尺寸缩放。

预处理：把图像整理成“正对、裁掉边缘”的样子。勾选需要的项，可用“上移 / 下移”调整顺序，选中某项后下方可调参数。

| 预处理 | 用途 |
| --- | --- |
| 裁剪页面 | 自动找出纸张轮廓并裁剪，适合手机拍摄 |
| 标记点定位裁剪 | 用答题卡四角的黑色定位标记对齐，需选一张标记点图片 |
| 色阶调整 | 调整黑白场与伽马，改善对比度 |
| 高斯模糊 / 中值模糊 | 去噪 |
| 特征点对齐 | 用参考图做对齐，适合版面轻微变形 |

常见搭配：

- 带黑色定位标记的卡：裁剪页面 → 标记点定位裁剪。标记点图片是把一个角上的标记单独截出的小图。
- 干净的扫描件：通常不需要预处理。

勾选或修改预处理后，预览会自动刷新。如果预览提示“预处理失败”，说明没找到纸张或标记点，此时画布显示的是原图，字段块位置仅供参考；请调整预处理或换一张图。

### 4. 量取气泡大小

点工具栏“量取气泡大小”，在画布上沿一个气泡的外沿拖出一个框，气泡大小会自动填入。也可以在“页面与预处理”里直接填宽高。

### 5. 自动识别版面（推荐先用）

换了新版式的答题卡时，不必从头框选。载入空白答题卡并确认预览正常后，点工具栏“自动识别版面”：

1. 程序用图像检测找出所有气泡，按间距聚成网格块，推断每块的题型（选择题或数字区）和排列方向，并自动给出题号和准考号字段。
2. 已有字段块时会询问“替换”还是“追加”。
3. 生成后对照底图检查，再按需要用后面的方法微调。

要点：

- 空白、清晰、正对的答题卡识别得最好。模糊、带明显噪点或严重倾斜的图识别率会下降，此时请先用预处理把页面整理好，或改用手动框选。
- 程序判断不了的地方（例如 4 位数字的准考号可能被当成 4 选项的选择题）在右侧改题型即可。
- 勾选“大模型修正”后，会把标注了编号的答题卡图发给视觉大模型，由它判断哪些块是误检、哪块是准考号、各题的选项字母和答题顺序。需要先在“设置 → 大模型辅助”里填接口地址、密钥和模型名称，并点“测试连接”确认可用；接口调用失败时会自动退回程序检测结果。
- 发送给大模型的只有这张答题卡的图片和各块的行列数，不包含学生答卷。使用外部接口前请确认空白答题卡可以外发。

### 6. 框选字段块

字段块是一组排列规则的气泡，比如“第 1~10 题的 ABCD”或“准考号的 9 列数字”。自动识别没有覆盖到的区域可以手动补框。

1. 点“框选字段块”，在画布上从首个气泡的左上角拖到末个气泡的右下角。
2. 松开后自动新建字段块并切回“选择 / 移动”，右侧“字段块”页签显示它的属性：

| 项目 | 说明 |
| --- | --- |
| 名称 | 随意，用于区分 |
| 题型 | 选择题 4 项、5 项、数字 0-9 等，也可选“自定义”并填选项 |
| 选项 | 自定义题型时填，如 `T,F` |
| 方向 | 自定义题型时选择选项是横排还是竖排 |
| 字段标签 | 每个字段的名字，`q1..10` 表示 q1 到 q10 |
| 按题号生成 | 填前缀、起始号和数量，点“生成”自动写好标签 |
| 外框 | X、Y、宽、高，与画布上的框同步 |

3. 程序会根据“外框 + 题数 + 选项数”自动算出气泡间距，并在画布上画出每个气泡的位置。调整字段标签里的题数，格子会重新铺满外框。
4. 对照底图检查格子是否与印刷的气泡对齐。没对齐时：
   - 拖动框内部可移动整个字段块，拖动边上的小方块可缩放；
   - 选中字段块后用方向键微调 1 像素，Shift+方向键移 10 像素；
   - 下方会提示“选项间距”和“字段间距”，间距小于气泡尺寸时会警告气泡重叠。
5. 再框下一个字段块，题号会自动接续。一个选中的字段块可以“复制”或“删除”（也可按 Delete 键）。

### 7. 准考号等多列字段

准考号通常是多列竖排的数字，每一列是一个字段：

1. 框选整个数字区域（9 列 × 10 行）。
2. 题型选“数字 0-9（纵向）”，字段标签填 `roll1..9`。
3. 到“页面与预处理”下方的“合并列”，点“添加”，列名填 `Roll`，包含的字段标签填 `roll1..9`。这样结果表里准考号是一列，如 `E503110026`。

### 8. 校验模板

右侧“校验”页签点“校验模板”。通过时会显示字段数量和输出列；字段标签重叠、字段块超出页面、合并列引用了不存在的标签等问题会在这里给出提示。

### 9. 文字区域：自动识别姓名、班级

答题卡上有手写或印刷的姓名栏、班级栏，又没有学号涂卡时，可以让大模型把它们读出来，带进结果表。

1. 先在“设置 → 大模型辅助”配置好接口，并点“测试连接”确认模型支持图片输入。
2. 在“版面模板”页点工具栏的“框选文字区（姓名）”，在答题卡上拖出姓名栏的范围（四周可略宽，要框住整个书写区）。第一个区域默认叫“姓名”，之后依次叫“文字区2”等；右侧“文字区域”页签里可以改名称、微调坐标、删除。可以框多个，如“姓名”“班级”。
3. 阅卷或扫描时，程序识别完涂卡后，把每个文字区域裁成小图交给大模型，结果显示在结果表里，列名就是区域名称，位置在“得分”之后。
4. 大模型可能读错，尤其是潦草的手写体。结果表里的文字列可以**双击直接修改**，修改会保存到该次结果中，导出时也使用修改后的内容。裁出的小图保存在输出目录的 `TextFields` 文件夹里，方便核对。

说明：每张卡每个区域会调用一次大模型，有耗时和费用；没有配置大模型时文字区域不会被识别，涂卡部分不受影响。

## 四、录入答案与评分

进入“答案评分”页。题号列表来自模板（已合并进“合并列”的字段不出现）。

**多套答案**：同一个版面可以保存多套答案（例如不同场次、A/B 卷）。页面顶部的“当前答案”可以切换、新建、复制、重命名和删除；下面编辑的内容都属于当前选中的这套。版面换新卡才需要新建方案，换场次只需要新建一套答案。阅卷和扫描时再选用其中一套（见下文）。

- 默认分值：答对、答错、未答各得多少分，答错可填负数（如 `-0.5`），也可填分数 `3/2`。
- 逐题录入：在“正确答案”列直接填；“答对分值”“答错分值”留空则用默认；多选题（答案为两个及以上选项，如 `ABD`）可在“漏选得分”填只选对一部分且没选错时的得分。
- 快速录入：在上方输入 `ABCDDBCA`，点“按顺序填入”，答案按题号顺序填入；多选题或选项为多字符时，用逗号分隔，如 `A,BC,D`。
- 从填涂好的答案卡导入：点“从填涂好的答案卡导入…”，选择一张按标准答案填涂好的答题卡（版式必须与当前方案一致），程序用识别引擎读出每题答案并填入表格，不需要大模型。没填涂的题保持为空，多涂的题会提示核对。
- 从答案表图片 / PDF 导入：点“从答案表图片 / PDF 导入…”，选择文字版答案表的图片或 PDF（PDF 最多读取前 4 页），由大模型读出题号和答案并填入。需要先在设置中配置大模型；导入后请务必核对一遍。
- 用自然语言设置评分规则：在“评分规则”框里描述，例如“1-20 题每题 2 分；21-25 题为多选题，每题 4 分，漏选得 1 分，错选不得分；26-30 题每题 3 分，答错扣 1 分”，点“生成评分设置”，大模型会把它转成默认分值和各题的单独设置，结果直接显示在下方表格中，可以继续手改。每次生成会覆盖表格里原有的单题分值设置，但不会改动已填的答案。
- 答案写法：

| 写法 | 含义 |
| --- | --- |
| `A` | 答案是 A |
| `AB` | 必须同时涂 A 和 B |
| `A|C` | 涂 A 或涂 C 都算对 |
| 空白 | 这道题不计分 |

## 五、扫描采集（摄像头 / 监控文件夹）

进入“扫描采集”页，可以边拍边识别，不用先攒一批图片。使用前先选好方案，并确保方案已有字段块。

开始前先在顶部选好“当前方案”（决定版面），并在本页的“使用答案”里选这一场用哪套答案；选“（不评分）”则只识别、不算分。扫描开始后答案选择会锁定，需要换答案请先结束本次扫描。

### 用摄像头逐张拍

1. 来源选“摄像头”，在下拉框选摄像头（首次进入页面会自动查找，约 5 秒；插拔设备后点“刷新摄像头”）。
2. 分辨率建议选 1920 × 1080；“摄像头默认”通常只有 640 × 480，气泡太小，识别不稳。
3. 点“开始扫描”。启动识别引擎和打开摄像头共需几秒，左侧出现取景画面后即可使用。
4. 把答题卡放入画面，四条边都要完整入画；检测到卡时画面上会出现彩色外框。点“拍照并识别”（或按空格键）拍一张，右侧表格马上追加这张的识别结果；点击表格某一行可在下方查看标注图。
5. 全部拍完点“结束并保存”。程序会先处理完已拍的图片，再把结果保存到输出目录，之后可以在“开始阅卷”页的历史记录里查看和导出。

可选开关（开始前设置）：

- 自动拍照：卡片入画并保持不动约 1 秒后自动拍照，同一张卡不会重复拍，卡片移开或换一张才会再拍。默认关闭，需要时手动勾选。
- 裁剪并校正后保存：按检测到的卡片轮廓把图裁成正对的整页再保存。方案里没有“裁剪页面”或“标记点定位裁剪”预处理时建议勾选；方案已有这些预处理时不要勾选，用原图即可。

拍摄建议：卡片平放、光线均匀避免反光、背景与纸张反差大（深色桌面最好）、摄像头固定不动。

### 监控文件夹（扫描仪、手机适用）

1. 来源选“监控文件夹”，选择扫描仪或手机保存图片的文件夹。
2. 点“开始扫描”。此后只要有新图片（jpg、png、pdf）出现在该文件夹里，程序就自动识别并追加到结果表。
3. 扫描仪的自带软件设置成“扫描后保存到该文件夹”即可；手机把照片传到电脑的这个文件夹也一样。
4. 点“结束并保存”收尾。注意：开始扫描时文件夹里已有的图片也会被识别，不想处理旧图片请先把它们移走。

## 六、批量阅卷

进入“开始阅卷”页。

1. 点“添加文件夹…”（会递归查找其中的图片和 PDF）或“添加文件…”，也可以直接把文件或文件夹拖进窗口。重复文件会自动去重。右上角的“使用答案”用来选这一批用哪套答案（默认是方案当前的答案，可选“（不评分）”）。
2. 点“开始阅卷”。进度条显示已处理数量，“显示日志”可查看引擎输出。需要中止时点“取消”。
3. 完成后结果表列出每张卡：

| 状态 | 含义 |
| --- | --- |
| 正常 | 正常识别 |
| 多涂 | 某题涂了多个选项，整行黄色高亮 |
| 失败 | 无法读取或预处理失败，整行红色高亮 |

4. 点击一行查看标注图，滚轮缩放，“打开原图”用系统看图软件查看原件。
5. 筛选框可选“仅异常”或“含未涂题”，方便核对。
6. “历史记录”下拉可回看之前的阅卷结果。
7. “导出结果…”导出 Excel（异常行带底色）或 CSV；“打开输出目录”直接打开本次结果文件夹，里面还有 `CheckedOMRs`（标注图）和 `Results`（原始 CSV）。

## 七、设置说明

左侧“设置”页，改完点“保存设置”，“恢复默认”可还原全部参数。

| 分组 | 参数 | 说明 |
| --- | --- | --- |
| 识别参数 | 纸张类型 | 白底深色笔迹选“白底” |
| | 阴影压制系数 | 0~1，越小越不怕阴影，但浅涂痕易漏 |
| | 最小灰度间隔、最小灰度跳变 | 涂得浅、漏识别多时适当调小 |
| | 跳变容差、置信余量 | 一般保持默认 |
| 图像尺寸 | 处理宽度、高度 | 识别前把图缩放到该尺寸；“版面模板”中可为单个方案设独立尺寸 |
| 自动对齐 | 启用及其参数 | 实验功能，扫描件有轻微错位时开启 |
| PDF 输入 | 渲染分辨率、读取页码 | 分辨率 0 为自动；页码留空读全部，可填 `1`、`1,3`、`2-5` |
| 输出 | 保存标注图 | 关闭后看不到标注图，但更省空间 |
| | 多选卷单独归类 | 开启后含多涂的卡不进结果表，记入“多涂”清单 |
| | 中间过程图级别 | 调试用，一般为 0 |
| 大模型辅助 | 接口地址、密钥、模型名称、超时 | 用于“自动识别版面”的大模型修正；接口为 OpenAI 兼容格式，模型需支持图片输入；密钥只保存在本机设置文件中 |
| 常规 | 输出目录、方案目录、完成后打开输出目录 | 路径与行为 |

## 八、常见问题

**程序打不开，提示 Failed to load Python DLL**
exe 没有和 `_internal` 在同一文件夹，或 `_internal` 里的文件被安全软件隔离。整个文件夹一起放，并把它加入信任列表。

**预览提示“预处理失败”**
没找到纸张或标记点。检查图片是否完整、光线是否均匀；使用标记点定位时确认标记点图片截取正确，或先去掉该预处理看原图。

**识别结果大量为空**
气泡网格与底图没对齐，或涂痕太浅。先回“版面模板”检查对齐，再到“设置”把“最小灰度间隔 / 最小灰度跳变”调小。

**识别出多余的涂选**
擦拭痕迹或阴影被当成涂选。适当调大“最小灰度间隔”，或用“色阶调整”提高对比度。

**阅卷时某张卡显示“失败”**
可能是图片无法读取或预处理没定位到页面。打开日志查看原因，必要时用原图单独检查。

**摄像头列表是空的 / 画面打不开**
确认摄像头已连接并且没有被微信、会议软件等占用；点“刷新摄像头”重试。部分摄像头的 4K 档位会自动降到 1080p。

**自动拍照一直不触发**
需要整张卡四边都在画面内、与背景有明显反差，并且保持静止约 1 秒。条件不好时可以直接用“拍照并识别”手动拍。

**换了一版答题卡**
新建一个方案（旧方案可用“复制”再修改），载入新卡后点“自动识别版面”，再核对微调。

**方案和结果文件在哪**
设置页“常规”里显示了方案目录和输出目录，也可点顶部“打开目录”直接打开当前方案所在文件夹。方案目录里的 `template.json`、`evaluation.json` 是 OMRChecker 原生格式，可以直接给命令行版使用。
