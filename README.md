# OMR 阅卷助手

基于开源项目 [OMRChecker](https://github.com/Udayraj123/OMRChecker) 的 Windows 桌面程序。用图形界面完成答题卡版面标注、答案录入、批量识别与结果导出，不需要手写 JSON 或使用命令行。

## 使用

1. 解压发行包，运行 `OMR阅卷助手.exe`。首次启动会自动安装“示例方案”和一张示例答题卡。
2. **版面模板**：载入空白答题卡图片，可点“自动识别版面”（可选大模型修正，需在设置中配置接口）一键生成字段块；也可以手动用“框选字段块”沿首个气泡左上角到末个气泡右下角拖出外框，右侧设置题型、题数和字段标签；用“量取气泡大小”框住单个气泡设定气泡尺寸。选中字段块后可拖动、缩放，方向键微调（Shift 为 10 像素）。
   版面中可以框出“文字区域”（姓名、班级），阅卷时由大模型识别并带入结果表，可双击修改。
3. **答案评分**：按题录入标准答案和分值；也可以输入 `ABCDDBCA` 按顺序快速填入。
4. **扫描采集**：连接摄像头逐张拍照识别（手动或自动拍照），或监控扫描仪、手机保存图片的文件夹，新图片自动识别。
5. **开始阅卷**：添加答题卡图片、PDF 或文件夹，点击“开始阅卷”。结果表中多涂、识别失败的卡片会高亮，点击一行可查看标注图，支持导出 Excel / CSV。
6. **设置**：识别阈值、处理尺寸、自动对齐、PDF 渲染、输出目录等全局参数。

方案保存在“文档\OMR阅卷助手\方案”，每次阅卷的结果按“方案名\时间”保存在“文档\OMR阅卷助手\输出”。方案目录内的 `template.json`、`evaluation.json` 与 OMRChecker 原生格式一致，可直接用于命令行版本。

### 预处理

在“版面模板 → 页面与预处理”中启用并排序。常用组合：

- 手机拍摄、带黑色定位标记的答题卡：裁剪页面 → 标记点定位裁剪（需提供标记点图片）。
- 扫描件：通常无需预处理，或仅使用色阶调整。

模板坐标基于预处理后、缩放到“页面尺寸”的图像。修改预处理后预览会自动刷新。

### 答案写法

- `A`：该题答案为 A。
- `AB`：要求同时涂 A 和 B。
- `A|C`：涂 A 或涂 C 均得分。
- 答案留空的题目不计分。
- “本题分值”留空时使用默认分值；答错分可填负数。

## 从源码运行与构建

开发与打包环境为 Python 3.14（Windows）。

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m app.main
```

打包发行版：

```powershell
.\build.ps1
```

产物位于 `dist\OMR阅卷助手`。

## 结构

- `app/`：桌面程序。`engine_runner.py` 是识别引擎的子进程入口，界面通过它执行阅卷、预览与模板校验。
- `vendor/OMRChecker/`：OMRChecker 源码（MIT 协议，保留原版权声明），未做修改。
- `assets/demo/`：内置示例方案，由 `tools/make_demo.py` 生成。
